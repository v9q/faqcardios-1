## Resposta rápida (bot / primeira mensagem)

O Dyna-MAPA AOP (e modelos equivalentes) pode se comunicar com o computador por **cabo/interface serial** ou por **Bluetooth** — é preciso selecionar a interface correta no próprio aparelho antes de tentar conectar.

## Passo a passo para orientar o cliente

1. Com o monitor **desligado**, garantir que não há cabo/adaptador USB conectado (a troca de interface é feita com o monitor desligado).
2. Ligar o monitor e, com o equipamento ligado, pressionar simultaneamente as teclas indicadas no manual até o visor mostrar o menu de interface.
3. Navegar até a opção Bluetooth e confirmar a seleção.
4. No computador, parear o Bluetooth do monitor como um novo dispositivo (o pareamento aparece no software de configuração, ex: CardioSmart).

## Quando escalar para atendimento humano

- Aparelho não entra no menu de seleção de interface (pode indicar problema de firmware/hardware).
- Pareamento Bluetooth aparece no Windows mas o software Cardios não reconhece o dispositivo.
- Bateria fraca — o manual recomenda conferir a tensão mínima das pilhas antes de diagnosticar como problema de conexão (pilhas NiMH devem estar ≥ 2,75V após remoção do carregador).

## Fonte / observações

Procedimento de seleção de interface Bluetooth extraído do Manual do Usuário Dyna-MAPA AOP (seção de configuração do monitor). Vale confirmar com o Filipe se o passo a passo exato de teclas é o mesmo em todos os modelos Dyna-MAPA em campo hoje, já que pode variar por versão de firmware.
