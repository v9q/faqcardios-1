# Assistência Técnica — pendente de conteúdo

Diferente das outras categorias, Assistência Técnica provavelmente não deve virar uma FAQ de autoatendimento — é o departamento com os casos mais longos e complexos (defeitos de hardware, envio de equipamento para reparo). O papel da FAQ/bot aqui é **triar rápido e direcionar certo**, não tentar resolver via bot.

Tópicos prováveis para desenhar o fluxo (não como FAQ, mas como triagem):
- Coleta de informações do defeito antes de abrir o chamado (modelo, nº de série, descrição do problema).
- Processo de envio/retorno de equipamento para reparo (existe material de "Declaração de envio" nos arquivos internos de Assistência Técnica).
- Definir SLA esperado para esse tipo de chamado, para o bot já informar o cliente na abertura.
