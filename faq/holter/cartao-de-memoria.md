## Resposta rápida (bot / primeira mensagem)

O cartão SD do seu gravador Holter (CardioLight, CardioLight+ ou CardioLoop) é o que armazena o exame **e** configura o aparelho. A maioria dos problemas de leitura/gravação cai em uma destas causas:

1. **Cartão de outro produto ou comprado fora da Cardios.** O gravador só é compatível com os cartões SD fornecidos pela Cardios para aquele modelo específico — cartões de outros produtos Cardios (ex: um cartão de MAPA num Holter) ou cartões comuns de loja não funcionam.
2. **Cartão não preparado antes do uso.** O cartão precisa ser preparado no **CardioSmart** ou **CardioNet** (com os dados do exame/paciente) antes de ser inserido no gravador. Um cartão "cru" não vai gravar corretamente.
3. **Encaixe invertido.** O encaixe do cartão deve seguir a orientação indicada no gravador (observe os pontos/marcas de referência) — inserir invertido pode danificar o cartão ou o próprio aparelho.
4. **Cartão usado para outra finalidade.** Nunca grave fotos ou outros arquivos no cartão do Holter — isso pode corromper os dados do exame.

## Passo a passo para orientar o cliente

1. Confirme o modelo do gravador (CardioLight, CardioLight+ ou CardioLoop) — os cartões não são intercambiáveis entre modelos.
2. Confirme se o cartão foi preparado no CardioSmart/CardioNet antes de ser colocado no gravador.
3. Peça para reinserir o cartão observando a orientação correta (ver manual, seção "Cartão SD").
4. Se o problema persistir mesmo com cartão original, preparado corretamente e bem encaixado, é caso de **encaminhar para o suporte técnico** — pode ser defeito físico do cartão ou do leitor do gravador.

## Quando escalar para atendimento humano

- Cliente já confirmou que o cartão é original, foi preparado corretamente e está bem encaixado, e o erro persiste.
- Suspeita de defeito de hardware (cartão ou gravador).
- Cliente com prazo urgente de laudo (Assistência Técnica pode ter fila — sinalizar prioridade).
